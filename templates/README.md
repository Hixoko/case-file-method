# Templates

Copy these into your own case file and fill them in. They are deliberately
skeletal — the structure is the useful part.

| Template | Goes to |
|---|---|
| [`case-index.md`](case-index.md) | your repo's `README.md` |
| [`document-README.md`](document-README.md) | `documents/YYYY-MM-DD-<slug>/README.md` |
| [`hypothesis.md`](hypothesis.md) | one entry in `analysis/hypotheses.md` |

See [METHOD.md](../METHOD.md) for the full directory layout.
